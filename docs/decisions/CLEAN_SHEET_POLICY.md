# Clean-sheet policy

The new IRIS repository is independently implemented. The legacy repository is a read-only knowledge source: this repository does not reuse its source, implementation text, tests, commit history, license headers, generated artifacts, or build output.

Contributors may learn behavioral requirements, architectural concepts, known failure modes, test scenarios, and operational or UX lessons, but must express resulting designs and documentation independently. When the distinction is uncertain, the material is not reused.

Third-party dependencies remain subject to their respective licenses. This policy records repository practice and does not make broader legal conclusions.
